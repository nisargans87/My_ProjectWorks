# My First Blog Project

A static personal learning blog introducing foundational web development concepts through HTML, CSS, and JavaScript educational content.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)

## Project Overview

This beginner-friendly webpage was created to learn and demonstrate the fundamentals of web development. It introduces its author and presents structured learning content about HTML, CSS, and JavaScript. The page itself is a static HTML document, with its CSS written inside the HTML file.

## Features

- About Me section with a personal introduction
- Learning sections covering HTML, CSS, and JavaScript
- Simple webpage layout with headings, paragraphs, and ordered lists
- Internal CSS styling
- LinkedIn profile and email contact links

## Technologies Used

- HTML5
- CSS3

JavaScript is discussed as educational content only; the project does not implement JavaScript functionality.

## Project Structure

```text
My_First_Blog_Project/
├── My_First_Blog_Project.html
└── README.md
```

## How to Run

1. Download or clone the repository.
2. Open `My_First_Blog_Project.html` in a web browser.

No server or installation is required.

## Learning Outcomes

- Structuring a webpage with HTML
- Styling HTML elements with CSS
- Organizing webpage content into sections
- Using headings, lists, links, and paragraphs
- Exploring clean webpage presentation and the role of JavaScript in web development

## Project Purpose

This project is a learning and practice exercise for strengthening fundamental web development concepts.
