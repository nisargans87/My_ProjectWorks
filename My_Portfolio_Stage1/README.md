## About the Project

**My_Portfolio_Stage1** is a personal portfolio website created as an initial web development project and a foundation for presenting my technical profile online.

The current version focuses on a simple, structured, and responsive-ready interface using only core front-end technologies. It demonstrates the use of semantic HTML for content organization and CSS for layout, typography, spacing, colors, and visual presentation.

This repository currently contains the static portfolio implementation using:

- HTML5
- CSS3

No JavaScript, frameworks, backend services, or external libraries are required for the current version.
